Kunci Gemini API

Belum ada key — AI pakai mesin offline

Ini konsep Bring Your Own Key: tiap akun Google bikin key Gemini gratis sendiri di aistudio.google.com/apikey, lalu tempel di sini. Key dipakai langsung dari perangkat/browser ini — aplikasi tidak menyediakan API key dari server. Kosongkan untuk menghapus key.

Kunci OpenRouter API

Belum ada key — AI pakai mesin offline

Bikin key gratis di openrouter.ai/keys lalu tempel di sini. Aplikasi memakai model gratis OpenRouter dan otomatis pindah ke model gratis lain kalau satu kena rate limit (429) / kuota habis. Key dipakai langsung dari perangkat ini — server tidak menyediakan API key.
